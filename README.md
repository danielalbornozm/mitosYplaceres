#  Mitos y Placeres

> Proyecto colaborativo desarrollado para las asignaturas de **Back End** y **Taller de Desarrollo de Soluciones**.

---

##  Descripción

Plataforma web desarrollada en **Django** enfocada en la gestión y publicación de contenidos, con renderizado de formularios responsivos y almacenamiento estructurado en base de datos relacional.

---

##  Tecnologías

* **Backend / Framework:** Django
* **Base de Datos:** MySQL (conector `mysqlclient`)
* **Gestión Multimedia / Imágenes:** Pillow
* **UI & Formularios:** `django-crispy-forms` + `crispy-bootstrap5` (Bootstrap 5)
* **Control de Versiones:** Git & GitHub

---

##  Instalación y Configuración Local

### Prerrequisitos
* Python 3.10+
* MySQL Server (en ejecución y con una base de datos creada para el proyecto)
* Entorno virtual (`venv`)
